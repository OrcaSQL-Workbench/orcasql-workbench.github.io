OrcaSQL Workbench 隐私政策

生效日期
2026年10月11日

OrcaSQL Workbench 是用于连接数据库、浏览对象、编写执行 SQL 和查看结果的HarmonyOS NEXT 数据库工作台。本应用不提供 OrcaSQL 账户注册或个人资料服务，但会处理数据库连接和 SQL 工作所需的数据，其中部分数据会保存在您的设备上。

我们处理哪些数据

本应用根据您配置连接、执行 SQL、选择文件、保存或导出等操作，处理完成相应功能所需的数据。这些操作涉及的是您指定的数据库账户，不是向开发者注册的 OrcaSQL 账户。数据库用户名、SQL 文本和业务查询结果可能包含个人信息或敏感信息，请只处理您具有合法权限的数据。

具体内容及用途

连接配置与数据库账号
您填写的连接名称、服务器地址、端口、数据库用户名、数据库名称、SSL/TLS 设置、所选文件路径及连接使用时间等，用于保存和管理配置、建立连接及数据库身份认证。

保存的数据库密码
用于后续数据库身份认证。连接密码单独通过系统 Asset Store Kit 保存，不作为明文密码字段嵌入普通连接配置。

SQL 与查询工作数据
您编写或主动导入的 SQL 文本、工作区草稿、编辑位置、连接绑定、启用后的执行历史，以及数据库返回的对象信息、服务器状态和查询结果，用于编辑、工作区恢复、执行记录、结果展示及您主动发起的导出。

您选择的文件
您主动选择的 SQL 文件、TLS 证书或私钥文件，以及保存或导出时选择的目标文件。应用按相应操作读取或写入文件；选择 TLS 文件时还会保留该文件的只读访问授权。

必要的诊断记录
启动、连接、执行等过程中的运行事件、时间、状态、错误码及用于关联问题的标记，用于故障定位。部分关联标记经过处理，但这不等同于完全匿名化。

本应用不以广告、用户画像或个性化推荐为目的使用这些工作数据，不要求您提供头像、昵称或 OrcaSQL 注册账户资料。

数据保存在何处，何时发生传输

设备上的应用工作数据

连接配置、已保存的数据库密码、SQL 草稿、启用后的执行历史及应用文件日志，由本应用保存在您使用的设备上。其中数据库密码由系统 Asset Store Kit 保存；SQL 草稿和执行历史位于应用私有工作目录。运行诊断还会使用设备的系统日志。

查询结果不自动写入工作区恢复文件。您主动保存 SQL 文件或导出查询结果时，数据写入您选择的位置；原始证书、私钥和导入文件也位于您选择的文件位置。如果该位置由第三方文件服务提供，相关存储受该服务的规则影响，不能一概视为本应用私有目录中的数据。

用户指定的数据库服务器

建立数据库连接、进行身份认证及执行您发起的 SQL 操作时，应用会与您指定的数据库服务器通信，发送必要的协议认证信息和 SQL，并接收服务器返回的信息或查询结果。本应用不将上述本地配置、草稿、历史或日志集中上传至开发者服务器。

本应用不统一指定数据库服务器所在国家或地区，也不承诺数据库服务器对数据采用某一种保留或备份规则。请您根据所连接的数据库服务，向相应服务器运营方确认部署地点、数据保存方式及适用规则。

网络通信是否使用 TLS 取决于您选择的连接模式及服务器能力。禁用 TLS 或允许回退的配置不能保证通信始终加密。请根据您的安全要求配置 TLS、证书校验和数据库访问权限。

系统文件授权与本应用的连接配置是不同的事项。您可以更改连接配置，停止在后续连接中使用某个文件。系统文件授权由系统另行管理；本应用没有专用的系统文件授权管理或撤销同意页面。

第三方组件与用户指定的服务

SQL 编辑和格式化使用随应用打包的 CodeMirror、SQL 语言组件和 sql-formatter 等本地组件。这些组件用于处理编辑内容，不由本应用将编辑内容上传给组件提供者。本应用未接入广告、用户画像或个性化推荐类服务。

您指定的数据库服务器，以及您选择的第三方文件位置，可能由您本人或其他服务提供者管理。此类通信或文件操作与开发者预设的广告、统计或资料共享服务不同。关于相应服务的数据处理问题，请查阅其规则或联系其运营方。

保留期限与清理方式

不同数据用于不同功能，不适用统一的“全部保存 30 天”规则。

当前实现的保留规则
数据
保留和清理方式

连接配置与保存密码
为后续连接保留。您可通过应用的连接删除操作移除相应保存配置和密码，并应留意操作是否成功及应用显示的错误信息。

SQL 执行历史
默认按 30 天、500 条及 5 MiB 上限管理，用户可以调整限制。超期或超限条目在载入、记录或调整设置时按存储流程淘汰，不代表应用关闭后仍有按日运行的删除任务。关闭后续历史记录不会自动清空已有记录；清空已有历史是另一个操作。

SQL 恢复草稿
用于恢复编辑工作，不设置统一的按天过期时间。工作区变化后的旧恢复文件按持久化流程清理；保存、清理或恢复异常时，原有文件可能继续保留以避免数据丢失。

诊断日志
应用文件日志按文件大小轮转，较旧文件会被替换或删除，不以某个固定天数作为统一的自动过期承诺。系统日志由系统管理。

外部文件与数据库数据
保存或导出的文件、原始证书或私钥文件，以及数据库服务器中的数据，不因清空本应用历史而一并删除。文件位置和数据库服务的保留规则需由您向相应管理者确认。

当前应用备份配置排除了 SQL 草稿及执行历史所在的私有目录。其他应用数据、系统日志或您选择的外部文件是否参与备份，取决于系统及相应文件服务的规则。

您可以管理的工作数据

本应用没有独立的个人资料页面、OrcaSQL 账户注册和账户注销流程。您可以通过下列数据库工作功能管理相关数据：

查看和编辑已保存的连接配置与数据库用户名，或删除不再使用的连接。
在 SQL 历史面板查看历史、调整保留限制、关闭后续记录或清空已有历史。
编辑、保存和关闭 SQL 文档，并按您的选择保存文件或导出已加载的查询结果。

保存的连接密码通过系统 Asset Store Kit 管理。本应用没有显示密码明文的个人资料页面，也没有专用的全局隐私同意撤回入口。对本应用数据处理有疑问，或需要了解本地操作方式时，可通过本声明的联系邮箱提出请求。

开发者不能仅凭邮件替您访问、修改或删除您的设备文件、第三方文件服务或数据库中的业务数据。涉及这些数据的访问、更正、删除或导出，应由有相应权限的使用者或运营方处理。本声明不限制您依法享有的权利。

SQL 文本可能包含您写入的密码或个人业务数据，不能因为连接密码采用系统安全存储，就认为草稿、历史和导出文件也得到完全相同的保护。SQL 还可能修改或删除数据库数据，查看结果表格不代表整个数据库连接是只读的。请避免在工作文本中保留不必要的敏感值，并确认您具有相应操作权限。

未成年人相关说明

本应用是数据库工作工具，不提供儿童账户或儿童专属服务，也没有独立的年龄认证流程。使用资格应符合适用法律、分发平台要求及实际授权。如您是未成年人，请在监护人指导下了解数据库操作风险。

应用不能自动识别您在 SQL 文本或数据库结果中处理的所有未成年人信息。处理此类信息前，请核验相应的合法权限。有关数据库内此类数据的权利请求，请联系相应数据库运营方；与本应用本地数据处理有关的问题，可使用下列联系方式。
