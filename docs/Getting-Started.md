# 入门指南

当前可用数据库引擎为 MySQL。

## 开始前准备

使用已获得的安装包安装并打开应用。本网站尚未提供下载链接，也不将开发测试包视为公开分发版本。

建立连接前，需要准备：

- MySQL 服务器地址和端口。
- 你有权使用的数据库用户名与密码。
- 可选的默认数据库名称。
- 数据库管理员要求的 TLS 模式、CA 证书，以及需要时使用的客户端证书和私钥。

不要把生产数据库密码或私钥放入公开文档、Issues 或演示截图。

## 创建连接

1. 点击工具栏的 **新建连接**，或从 **文件 → 新建连接…** 打开连接对话框。
2. 在数据库引擎选择界面选择 **MySQL**，点击 **继续**。
3. 在 **常规** 页面填写连接名称、主机、端口、用户名和密码；按需填写 **默认数据库（可选）**。
4. 根据服务器要求选择 SSL 模式。证书、客户端密钥和 TLS 版本等设置位于 **SSL / TLS** 页面。
5. 点击 **测试连接**。查看测试结果中的服务器信息及实际使用的 TLS 或普通 TCP 状态。
6. 点击 **保存** 只保存配置，或点击 **保存并连接** 保存后建立连接。

测试成功不等于设置已经保存。保存失败时，以界面显示的错误为准，不要假定配置和密码已经更新。

连接字段和 TLS 含义见 [连接管理与 TLS](Connections.md)。

## 进入查询编辑器

连接建立后，可通过 **工具 → 查询编辑器** 进入 SQL 工作区。执行前确认 **当前数据库连接** 和 **当前数据库** 的选择。

输入或打开你有权执行的 SQL，确认操作影响后，再使用 **执行当前语句或选中内容**。

SQL 不局限于查询；修改和删除语句会按数据库账户的权限执行。建议先使用合适的非生产环境熟悉操作，不要把结果表格的查看方式当作数据库只读保护。

## 查看执行结果

- **结果** 展示数据库返回并已加载的数据。
- **消息** 展示执行概要、错误及状态信息。
- **历史** 提供执行记录的搜索与管理。

后续操作见 [SQL 编辑与执行](SQL-Editor.md)、[结果查看与导出](Results-and-Export.md) 和 [SQL 历史与文件](History-and-Files.md)。
