# 连接管理与 TLS

当前连接选择器提供 MySQL。

## 常规连接字段

| 字段 | 说明 |
| --- | --- |
| 连接名称 | 用于识别已保存的配置 |
| 主机 | 你指定的数据库服务器地址 |
| 端口 | MySQL 新连接默认值为 3306，按实际服务配置填写 |
| 用户名、密码 | 数据库身份认证信息，不是 OrcaSQL 注册账户 |
| 默认数据库（可选） | 连接时希望使用的数据库 |
| SSL 模式 | 新建连接默认选择 **优先**；按你的安全要求调整 |

**高级** 页面提供连接超时和自动提交设置。新连接默认连接超时为 10,000 ms，自动提交开启。

## TLS 模式

| 界面选项 | 使用含义 |
| --- | --- |
| 已禁用 | 不要求使用 TLS，不能据此保证通信加密 |
| 优先 | 服务器支持时使用 TLS，不能保证所有情况下都加密 |
| 必须 | 要求使用 TLS；不要把它等同于已经验证服务器身份 |
| 验证 CA | 验证服务器证书的信任链 |
| 验证身份 | 在证书验证基础上验证服务器身份 |

如果你的安全要求是不允许明文或回退，不应仅依赖 **优先**。使用数据库管理员提供的模式和证书要求，并查看连接测试报告的实际 TLS 状态。

## 证书和私钥文件

在 **SSL / TLS** 页面：

- 需要验证服务器证书时，配置 **CA 证书**。
- 服务器要求客户端证书认证时，配置 **客户端证书** 和与其匹配的 **客户端私钥**。
- 当前界面可选择 TLSv1.2 或 TLSv1.3，新连接默认选择 TLSv1.2。
- 需要指定密码套件时，在对应字段填写服务器与客户端都能使用的配置。

通过 **浏览** 选择文件。应用会为选定的 TLS 文件保留只读访问授权，供后续连接使用；这不意味着应用获得整个文件目录的权限。

证书和私钥仍位于你选择的位置。移动、删除文件或更改系统授权后，需要重新核对连接所使用的文件。

## 测试、保存与连接

**测试连接** 检查当前填写的配置，并显示连接结果。它不会代替保存操作。

**保存** 保存配置；**保存并连接** 保存后建立连接。出现错误或“尚未保存”提示时，不应假定设置和凭据已经写入。

编辑连接如果涉及仍在使用的会话或未完成事务，可能需要先处理界面提示的操作。提交和回滚会影响数据库事务，请确认意图后选择，不要为完成保存而盲目提交。

## 删除连接

**删除连接** 会移除相应保存配置和密码。该操作不是删除数据库服务器中的业务数据，也不会自动删除原始证书、私钥或已经导出的文件。

如果提示保存密码不可用，按界面要求解锁设备后重试；不要假定应用已读取或替换了原密码。

执行与事务说明见 [SQL 编辑与执行](SQL-Editor.md)，本地数据范围见 [隐私政策](https://orcasql-workbench.github.io/privacy/)。
