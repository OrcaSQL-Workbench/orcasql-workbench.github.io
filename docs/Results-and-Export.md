# 结果查看与导出

适用版本：OrcaSQL Workbench 0.1.0。

## 结果与消息

查询工作区包含 **结果**、**消息** 和 **历史**。

- **结果** 展示已经加载到应用的数据。
- **消息** 展示执行概要、错误、取消或未知结果等状态。
- 不返回结果集的语句，应结合消息和影响行数判断结果，不能仅凭空表格认定执行失败。

## 已加载行不等于全部数据

界面可能同时展示总行数、已加载行数和当前可见行数。**最大行数**、结果截断和筛选会影响实际可查看的数据范围。

**筛选行** 作用于已加载的结果行，不是在服务器重新执行查询，也不保证包含未加载的数据。

如果结果被截断，导出或复制当前结果不能代替全量数据库导出。

## 复制

复制按钮会根据当前选择，处理单元格、所选内容、筛选结果或已加载数据。

界面提供完整单元格值的查看与复制入口。复制行数过多或内容过大时，会要求缩小选择范围；当前提示限制为最多 10,000 行及 8 MiB。

复制失败时，以界面状态为准，不要假定剪贴板已经更新。

## 导出 CSV 或 JSON

1. 等待所选结果完成并有可用数据。
2. 打开 **导出已加载的行**，选择 CSV 或 JSON。
3. 使用 CSV 时，可调整列标题、分隔符、引号、行结束符和 NULL 表示方式。
4. 选择文件保存位置，查看导出操作的结果。

导出的对象是所选结果已经加载的行，不会自动补齐未加载数据。

结果截断时，应用会提示实际导出范围。确认 **导出已加载数据** 前，请核对这是否满足用途。

## 数据安全

查询结果和导出文件可能包含业务数据或个人信息。保存到第三方文件位置时，还会受到该文件服务规则的影响。

清空 SQL 历史不会删除导出文件，也不会删除数据库中的数据。不要在 Issues、邮件或截图中直接提交真实业务结果。

相关说明见 [SQL 编辑与执行](SQL-Editor.md)、[SQL 历史与文件](History-and-Files.md) 和 [隐私政策](https://orcasql-workbench.github.io/privacy/)。
