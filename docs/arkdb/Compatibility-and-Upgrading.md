# 兼容性与升级

本页说明 `@arkdb/mysql` 1.1.0 的运行环境、功能范围和升级方法。

本页内容：[版本和平台](#版本和平台)、[支持范围](#支持范围)、[升级 HAR](#升级-har)、[接口兼容](#接口兼容)、[验证范围](#验证范围)。

## 版本和平台

| 项目 | 要求 |
| --- | --- |
| 当前版本 | [1.1.0](https://github.com/OrcaSQL-Workbench/ArkDB/releases/tag/mysql-v1.1.0) |
| HarmonyOS | 6.1.1 / API 24 |
| 设备类型 | tablet、2in1 |
| 包格式 | 使用规范化 OHM URL 的字节码 HAR |
| 安装方式 | 在应用模块中使用本地 HAR 依赖 |

## 支持范围

1.1.0 提供文本查询、TLS、类型化预处理、命名参数、流式读取、批处理、受限多行 INSERT、只读游标、长参数、存储过程 OUT/INOUT、事务与保存点、语句截止时间、查询取消、会话重置、元数据和服务器指标。

连接池、Worker 和断线重连由应用管理。驱动不会在连接失败后自动重放 SQL。

## 升级 HAR

1. 从目标版本的发布页下载 HAR、校验文件和清单，并核对 SHA-256。
2. 替换项目中的 HAR，更新模块依赖路径。
3. 重新执行 OHPM 依赖恢复并构建应用。
4. 检查编译错误以及自定义 Worker 消息、TLS 配置和结果处理。
5. 在目标设备和 MySQL 环境中完成连接、查询、事务和超时测试后再发布应用。

不要混用不同版本的 HAR、校验文件和清单。升级后仍无需添加 `@arkdb/core` 依赖。

## 接口兼容

1.1.0 保留 1.0.2 的包根连接、查询、取消和结果类型。原有代码可以继续使用 `DbDriverFactory`、`DbConnection` 和 `QueryResult`；新增功能通过 `mysqlFeatures` 提供。

升级时重点检查：

- 是否启用了新的会话配置、文本多语句或预处理缓存；
- 是否需要改用类型化预处理，避免拼接外部输入；
- 是否正确处理 `truncated`、`statusKnown` 和不确定执行结果；
- 是否在 Worker 中串行使用同一连接。

完整接口见[公共接口与错误处理](API-Reference.md)，版本变化见[发布说明](https://github.com/OrcaSQL-Workbench/ArkDB/blob/mysql-v1.1.0/mysql/CHANGELOG.md)。

## 验证范围

在用于实际业务前，请在目标设备、目标 MySQL 版本和实际网络环境中至少验证：

- TLS 证书链与主机名校验；
- 账号使用的认证方式；
- 业务涉及的数据类型与结果规模；
- 事务提交、回滚和断线后的结果核对；
- 查询取消、语句超时和连接复用；
- Worker 生命周期以及应用退出时的连接清理。

开始接入请阅读[下载与快速接入](Getting-Started.md)。
